# 深蹲教練 (Squat Coach)

單檔 MediaPipe 深蹲自我檢測工具，繁體中文介面。

## 本機預覽
```bash
python3 -m http.server 8765
# 開 http://127.0.0.1:8765 （相機需 HTTPS 或 localhost）
```

## 手機用法
1. 手機架三腳架，鏡頭約髖部高度，距離 2–3 公尺，全身入鏡
2. 用瀏覽器打開 HTTPS 網址，允許相機
3. 選「側面」、後鏡頭，按開始偵測
4. 做完按「停止並儲存」看紀錄

## GitHub Pages（建議永久網址）
把此資料夾推到公開 repo `squat-coach` 的 `main`，Settings → Pages → Deploy from branch `main` / root。
